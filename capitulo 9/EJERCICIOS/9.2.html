EJERCICIO DE AUTOEVALUACIÓN 9.2

Para el programa de la figura 9.13, indique el alcance (ya sea alcance global o de función) de cada uno de los siguientes elementos:

<!DOCTYPE html>

<!-- Ejercicio 9.2: cubo.html -->
<html>
   <head>
      <meta charset = "utf-8">
      <title>Alcance</title>
      <script>
        var x;

         function salida()
         {
            for ( x = 1; x <= 10; x++ )
               document.writeln( "<p>" + cubo( x ) + "</p>" );
         } // fin de la función salida

         function cubo( y )
         {
            return y * y * y;
         } // fin de la función cubo

         window.addEventListener( "load", salida, false );
      </script>
   </head><body></body>
</html>
  • a) La variable x.
    Alcance global.
  • b) La variable y.
    Alcance de función.
  • c) La función cubo.
    Alcance global.
  • d) La función salida.
    Alcance global.
