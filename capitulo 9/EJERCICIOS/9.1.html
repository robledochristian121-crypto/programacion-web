EJERCICIO DE AUTOEVALUACIÓN 9.1

Complete las siguientes oraciones:

  • a) Los módulos de programa en JavaScript se llaman funciones.
  • b) Una función se invoca mediante el uso de un(a) llamada a función.
  • c) Una variable que se conoce sólo dentro de la función en la que se define se llama variable local.
  • d) La instrucción return en una función invocada puede usarse para pasar el valor de una expresión de regreso a la función que hizo la llamada.
  • e) La palabra clave function indica el comienzo de la definición de una función.
