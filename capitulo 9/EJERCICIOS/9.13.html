EJERCICIO 9.13

Escriba una función llamada potenciaEntera( base, exponente ) que devuelva el valor de base elevada al exponente. Por ejemplo, potenciaEntera( 3, 4 ) = 3 * 3 * 3 * 3. Suponga que exponente y base son enteros. La función potenciaEntera debería usar una instrucción for o while para controlar el cálculo. Incorpore esta función en una secuencia de comandos que lea los valores enteros de un formulario de HTML5 para base y exponente, y que realice el cálculo con la función potenciaEntera. El formulario de HTML5 deberá consistir de dos campos de texto y un botón para iniciar el cálculo. El usuario debe interactuar con el programa, escribiendo números en ambos campos de texto y luego haciendo clic en el botón.
