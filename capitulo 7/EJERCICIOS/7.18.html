EJERCICIO 7.18

Sin ejecutar la siguiente secuencia de comandos, determine lo que imprime:
var fila = 10;
var columna;

while ( fila >= 1 )
{
   columna = 1;
   document.writeln( "<p>" );

   while ( columna <= 10 )
   {
      document.write( fila % 2 == 1 ? "<" : ">" );
      ++columna;
   } // end while

   --fila;
   document.writeln( "</p>" );
} // end while

    Imprime 10 líneas de 10 símbolos cada una, alternando entre > y <:
    la primera línea (fila = 10, par) es >>>>>>>>>>,
    la segunda (fila = 9, impar) es <<<<<<<<<<,
    y así sucesivamente hasta la fila 1, que es <<<<<<<<<<.
    (El operador ?: escribe "<" si fila es impar y ">" si es par.)
