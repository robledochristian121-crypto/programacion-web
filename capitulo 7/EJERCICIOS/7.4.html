EJERCICIO DE AUTOEVALUACIÓN 7.4

Escriba una instrucción en JavaScript para realizar cada una de las siguientes tareas:

    a) Declarar las variables suma y x.

    var suma, x;

    b) Asignar 1 a la variable x.

    x = 1;

    c) Asignar 0 a la variable suma.

    suma = 0;

    d) Sumar la variable x a suma y asignar el resultado a la variable suma.

    suma += x;
    o también: suma = suma + x;

    e) Imprimir "La suma es: ", seguido del valor de la variable suma.

    document.writeln( "La suma es: " + suma );
