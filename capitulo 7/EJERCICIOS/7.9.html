EJERCICIO 7.9

Identifique y corrija los errores en cada uno de los siguientes segmentos de código. [Nota: puede haber más de un error en cada fragmento; a menos que haya declaraciones presentes, suponga que todas las variables están declaradas e inicializadas correctamente].

    a) if ( edad >= 65 );
       document.writeln( "Edad es mayor o igual que 65" );
    else
       document.writeln( "Edad es menor que 65 )";

    Error 1: el ; después de la condición del if. Con ese punto y coma, el else queda sin su if y es un error de sintaxis.
    Error 2: las comillas de cierre de la última línea están mal colocadas (debe ser "Edad es menor que 65" );).
    Corrección:
    if ( edad >= 65 )
       document.writeln( "Edad es mayor o igual que 65" );
    else
       document.writeln( "Edad es menor que 65" );

    b) var x = 1, total;
    while ( x <= 10 )
    {
       total += x;
       ++x;
    }

    Error: la variable total no se inicializó. Su valor es undefined, y total += x produce NaN.
    Corrección: var x = 1, total = 0;

    c) var x = 1;
    var total = 0;
    while ( x <= 100 )
       total += x;
       ++x;

    Error: faltan las llaves del while. Sin ellas, sólo total += x; forma parte del ciclo y x nunca cambia (ciclo infinito).
    Corrección:
    while ( x <= 100 )
    {
       total += x;
       ++x;
    }

    d) var y = 5;
    while ( y > 0 )
    {
       document.writeln( y );
       ++y;
    }

    Error: ++y incrementa y, por lo que nunca llega a 0 (ciclo infinito).
    Corrección: usar --y; para decrementar la variable.
