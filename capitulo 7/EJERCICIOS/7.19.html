EJERCICIO 7.19

(Problema del else suelto) Determine la salida de cada uno de los siguientes segmentos de código, cuando x es 9 y y es 11, y cuando x es 11 y y es 9. Observe que el intérprete ignora la sangría en una secuencia de comandos. Además, el intérprete de JavaScript siempre asocia un else con el if anterior, a menos que se le indique de otra forma mediante la colocación de llaves ({}).

    a) if ( x < 10 )
    if ( y > 10 )
    document.writeln ( "<p>*****</p>" );
    else
    document.writeln( "<p>#####</p>" );
    document.writeln( "<p>$$$$$</p>" );

    Con la sangría correcta se ve que el else pertenece al if interior y que la última instrucción siempre se ejecuta:
    if ( x < 10 )
       if ( y > 10 )
          document.writeln( "<p>*****</p>" );
       else
          document.writeln( "<p>#####</p>" );
    document.writeln( "<p>$$$$$</p>" );
    Cuando x = 9 y y = 11: se imprime ***** y $$$$$
    Cuando x = 11 y y = 9: sólo se imprime $$$$$

    b) if ( x < 10 )
    {
    if ( y > 10 )
    document.writeln( "<p>*****</p>" );
    }
    else
    {
    document.writeln( "<p>#####</p>" );
    document.writeln( "<p>$$$$$</p>" );
    }

    Aquí las llaves hacen que el else pertenezca al if exterior:
    Cuando x = 9 y y = 11: se imprime *****
    Cuando x = 11 y y = 9: se imprime ##### y $$$$$
