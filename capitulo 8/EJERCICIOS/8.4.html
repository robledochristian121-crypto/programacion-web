EJERCICIO 8.4

Encuentre el error en cada uno de los siguientes segmentos de código. [Nota: puede haber más de un error].

  • a) For ( x = 100, x >= 1, ++x )
       document.writeln( x );
    Errores: for debe ir en minúsculas; las expresiones del encabezado se separan con punto y coma (;) y no con comas; y ++x debe ser --x para contar hacia atrás.
    Corrección: for ( x = 100; x >= 1; --x )
  • b) El siguiente código debe imprimirse sin importar si el valor entero es par o impar:
    switch ( valor % 2 )
    {
      case 0:
        document.writeln( "Entero par" );
      case 1:
        document.writeln( "Entero impar" );
    }
    Error: Falta una instrucción break en el case 0; cuando el valor es par también se imprime "Entero impar".
    Corrección: Agregar break; después de document.writeln( "Entero par" );
  • c) El siguiente código debe imprimir los enteros impares del 19 al 1:
    for ( x = 19; x >= 1; x += 2 )
       document.writeln( x );
    Error: x += 2 aumenta x en lugar de disminuirlo, por lo que el ciclo es infinito.
    Corrección: for ( x = 19; x >= 1; x -= 2 )
  • d) El siguiente código debe imprimir los enteros pares del 2 al 100:
    contador = 2;
    do {
       document.writeln( contador );
       contador += 2;
    } While ( contador < 100 );
    Errores: While debe ir en minúsculas (while); y la condición contador < 100 provoca que no se imprima el 100.
    Corrección: } while ( contador <= 100 );
