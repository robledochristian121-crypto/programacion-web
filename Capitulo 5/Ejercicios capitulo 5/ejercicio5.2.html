Indique si cada uno de los siguientes enunciados es VERDADERO o FALSO, explique por que

a) La regla @font-face especifica que se utilizara una fuente inscrustada cuando el documento se despligue en una pantalla de computadora.

VERDADERO O FALSO

b) Podemos usar gradientes en cualquier propiedad que acepte una imagen.

VERDADERO O FALSO

c) Un gradiente horizontal cambia en forma gradual de arriba hacia abajo.

VERDADERO O FALSO

Un gradiente horizontal cambia gradualmente de izquierda a derecha (o de derecha a izquierda). El que cambia de arriba hacia abajo es un gradiente vertical.

d) Podemos agrergar lineas entre columnas mediante el uso de la propieda column-gap

VERDADERO O FALSO

La propiedad column-gap especifica el espacio o separación entre las columnas. Para agregar líneas divisorias visibles entre ellas se utiliza la propiedad column-rule.

e) La regla @media determina el tipo y tamano del dispositivo en el que se despliega la pagina. Cuando el navegador examina la regla, el resultado es verdadero o falso. Los estilo de la regla se aplican solo si el resultado es falso

f) Para agregar multiples imganes de fondo a un elemento, usamos la propiedad background-position para especificar en donde colocar cada imagen mediante el uso del modelo de cajas.

VERDADERO O FALSO

Para colocar cada imagen de fondo en una posición específica se usa background-position, pero para especificar qué parte del modelo de cajas sirve de referencia o recorte para la ubicación se utilizan background-origin y background-clip.
