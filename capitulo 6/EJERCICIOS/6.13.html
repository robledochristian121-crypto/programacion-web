Dada y = ax³ + 7, ¿cuáles de las siguientes instrucciones de JavaScript son correctas para esta ecuación?

    a) y = a * x * x * x + 7;

    Correcta.

    b) y = a * x * x * ( x + 7 );

    Incorrecta: el 7 se suma antes de multiplicar.

    c) y = ( a * x ) * x * ( x + 7 );

    Incorrecta: el 7 se suma antes de multiplicar.

    d) y = ( a * x ) * x * x + 7;

    Correcta.

    e) y = a * ( x * x * x ) + 7;

    Correcta.

    f) y = a * x * ( x * x + 7 );

    Incorrecta: calcula a·x·(x² + 7).

    Respuesta: a), d) y e)
