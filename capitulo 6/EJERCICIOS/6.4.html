EJERCICIO DE AUTOEVALUACIÓN 6.4

Identifique y corrija los errores en cada una de las siguientes instrucciones:

    a) if ( c < 7 );
        window.alert( "c es menor que 7" );

    Error: no debe haber un punto y coma después del paréntesis derecho de la condición en la instrucción if.
    Corrección: elimine el punto y coma después del paréntesis derecho.
    if ( c < 7 )
        window.alert( "c es menor que 7" );
    [Nota: con el punto y coma, la instrucción de salida se ejecuta sin importar que la condición sea verdadera o no. El punto y coma se considera una instrucción vacía: una instrucción que no hace nada.]

    b) if ( c => 7 )
        window.alert( "c es igual o mayor que 7" );

    Error: el operador relacional => es incorrecto.
    Corrección: cambie => por >=.
    if ( c >= 7 )
        window.alert( "c es igual o mayor que 7" );
